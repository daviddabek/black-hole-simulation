# Black Hole Simulation

A 3D visualization of a black hole and its effect on space-time, 
built with Python and the Ursina Engine.

## Project Goals

- Create an interactive 3D black hole environment
- Create a black hole object to visualise the accretion disk to display 
a black holes effect on light
- Visualize simplified spacetime curvature in a 3D space
- Experiment with gravitational lensing
- Create a pixelated retro-computer visual style

## Technology

- Python
- Ursina Engine
